# 健康趋势记录 v2

移动端优先的 Apple Health 风格健康记录网页。UI 结构参考了用户提供的 HRT Tracker 网站以及 iOS 健康类应用的记录方式。

本版本增加：
- 日期切换
- 每日记录数量
- 治疗记录的“今天/全部”
- 实际化验趋势
- 连续记录天数
- 状态摘要
- JSON 导入/导出
- 本地提醒时间设置（仅保存设置，不负责调整治疗方案）

安全范围：不计算药物剂量、不预测血药浓度、不提供处方调整建议。


## V3 趋势分析
新增“趋势分析”卡片：使用已经录入的实际化验数据做简单统计回归趋势线，仅用于可视化历史数据的总体变化方向。它不模拟药物浓度、不计算剂量、不预测个体药效。
