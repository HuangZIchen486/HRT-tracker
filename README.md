# 健康趋势记录（Apple Health 风格）

这是一个纯前端、移动端优先的健康记录网页原型。

## 功能
- 摘要页
- 医生方案/处方治疗记录（自定义名称）
- E2 / T 实际化验结果趋势
- 身体变化、心情、不适记录
- JSON 导出备份
- localStorage 本地保存
- iPhone Safari 友好布局

## 安全设计
本项目不计算血药浓度，不根据记录推荐剂量，不预测如何调整处方。具体药物和方案由用户按医生提供的信息自行记录。

## 使用
直接用浏览器打开 `index.html` 即可。若要长期使用，可把整个目录放进自己的静态网页托管/GitHub Pages。
